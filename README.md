# Budget App - Python 💰

A professional budget tracking application built with Python. This project implements a category-based ledger system to manage finances, track spending, and visualize data.

## 🚀 Features
- **Category Management**: Create multiple categories for different types of expenses.
- **Financial Operations**:
  - `deposit()`: Add funds to a category.
  - `withdraw()`: Remove funds if the balance is sufficient.
  - `transfer()`: Move money between categories.
- **Balance Tracking**: Real-time balance calculation for each category.
- **Data Visualization**: Generates a text-based spending chart to visualize the percentage of spending per category.

## 🛠️ Technical Implementation
This project demonstrates several core Python concepts:
- **Object-Oriented Programming (OOP)**: Use of classes and methods to organize the budget system.
- **Data Structures**: Implementation of lists and dictionaries to store ledger entries.
- **String Formatting**: Advanced use of f-strings and padding for a professional table-like output.
- **Algorithmic Logic**: Implementation of a custom chart generator based on percentage calculations.

## 📖 How to Run
1. Clone the repository.
2. Run the `Budget_app.py` file using Python 3.
3. Use the `Category` class to manage your budget.
